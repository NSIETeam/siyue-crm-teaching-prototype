# 拼团推广内容与专属报名链接

## 保存与发布

promotion.create 和 promotion.update.patch 接受下列专用字段：

| 字段 | 用途 | 新提交内容限制 |
| --- | --- | --- |
| promotionTitle | 推广标题 | 20 个 Unicode 码点 |
| promotionSubtitle | 推广副标题 | 20 个 Unicode 码点 |
| promotionIntroduction | 推广介绍 | 50 个 Unicode 码点 |
| posterBackground | 海报背景 | 空串、#RRGGBB 或 2048 字符以内的公开 HTTPS 图片 URL |

文本去除首尾空白后按 Unicode 码点计数，保留原有中文标点。前后端共用 promotion-content.js，不使用 UTF-16 长度截断 emoji。只有新提交的专用字段触发该限制，未配置专用标题或介绍的旧活动继续回退 name / description，不迁移或截断历史字段。

专用字段随现有活动数据保存，修改后活动回到草稿，须再次发布。预览、幂等提交、版本冲突、校区授权和审计沿用原有活动流程。推广文字不改变优惠计算、成团人数、报名、收款或退款规则。

背景 URL 拒绝非 HTTPS、账号密码信息、控制字符、本机域名及私网 IP 字面量（包含 URL 规范化后的 IPv4 和 IPv6）。校验不会抓取图片或解析远端 DNS。背景图片只作为经过校验的 img src 显示，颜色仅接受六位十六进制值，不能提交任意 CSS。公开页面对标题、副标题、介绍、地址及课程文本进行 HTML 转义。

## 专属公开链接

活动链接格式为 commerce-store.html?promotionId=<活动编号>&type=group；联报使用 type=joint。本地二维码组件将同一个活动链接编码到二维码中，不向第三方二维码服务发送链接。

公开页面调用 GET /crm-api/v1/public/store?promotionId=...&type=...。服务端仅在活动已发布、发布版本与当前版本一致、未结束、处于有效日期，且适用商品和班级仍有效上架时返回该活动。返回商品/班级按该活动范围筛选；不返回草稿、其他活动、学员名单、买家、负责人或审计数据。有效链接继续锁定本活动，不在原表单中自动替换活动。

## 失效链接后的课程与优惠

流程为：打开专属链接 → 请求原活动 → 原活动有效则展示其专属海报和报名表；原活动接口明确返回 404 时显示“原活动已失效或暂不可报名”，再单独读取不带查询参数的公开课程目录。格式无效的活动链接直接显示固定提示并读取公开目录，不将原参数反射到页面或推荐链接。500、网络错误及内容不完整的成功响应保留原活动加载失败与重试，不静默转为活动失效。

推荐区与原活动报名状态分开。仅展示 availableForApplication 为 true、至少一个班级有正余位且有未取消/未结束未来课次的课程；拼团活动至少有一个活动范围内且校区匹配的班级余位足够一整团，联报活动每门课程都须有范围内且校区匹配的余位班级。活动发布、有效日期和新申请额度由公开目录服务端判定，前端不根据 total 推断个人资格或剩余优惠额度。原失效活动不会在推荐中继续显示。

课程“查看班级”进入不带原活动参数的普通商城，并定位对应课程；优惠“查看活动”进入该活动自身的 promotionId/type 专属链接。活动有正数优惠门槛时，按现有规则展示拼团的每人课程原价门槛、联报的课程原价合计门槛；不拆分或推导每门优惠价。推荐页不展示原活动报名表，不携带其待报价/待提交内容，也不自动套用新活动。目录加载失败可独立重试；没有合适课程或活动时分别显示空态。余位、优惠参与次数、课程时间冲突和实际优惠资格仍以重新报价与后台核对为准，推荐卡片不代表付款或报名成功。

公开海报展示实际保存的专用内容（以及旧字段回退）、有效日期、优惠、成团人数和本活动二维码。页面提供“保存 / 打印活动海报”，打印样式只输出海报；报名仍遵循整团登记与人工核对收款。

## 验证

- backend/test/promotion-presentation-http.test.cjs：通过隔离 HTTP 操作保存配置、重启服务读回、发布/编辑/停止的公开可见性、活动商品范围、Unicode 上限、背景安全、字段白名单及跨校区授权。
- backend/test/public-catalog-availability.test.cjs：公开目录排除无有效未来课次或无余位的班级，按新申请总额度及整团/联报范围容量筛选活动；保留已接受订单后续核对收款的流程。
- frontend-tests/promotion-public.test.cjs：专属活动选择与表单绑定、实际本地 QR 编码目标、HTML 转义；404 后独立公开目录、当前课程/活动链接与筛选、空态、目录重试、服务异常不静默回落、格式错误不反射参数及旧字段回退；包含真实隔离 HTTP 的失效活动到公开目录展示链路。
- 既有商城与整团报名回归保留报价校验、幂等重试、容量、整单收款及退款约束。
