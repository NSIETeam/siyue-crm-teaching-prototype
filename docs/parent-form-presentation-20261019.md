# 家长填写表单的展示规范（2026-10-19）

家长公开表单 `public-form.html` 沿用课程页的浅色图文风格，填写过程保持单列。标题区以较小标题、说明和装饰插图组成：信息登记使用书本与铅笔，问卷使用清单；插图仅用于装饰，不宣称存在未配置的课程或活动。

- 标题 21px（手机 20px）、全局说明 13px、字段标签 14px，输入与选择控件保留 16px，避免手机聚焦时自动放大。输入至少 46px，选项触控区域至少 44px，提交按钮至少 48px。
- 已配置图片继续处于发布字段的原始位置，以完整图片显示，不裁掉课程介绍文字；图片标题作为替代文字及图注。图片失效时保留装饰插图、图注和明确提示，不阻断填写。
- 公开 HTTPS 图片复用 `promotion-content.js` 的公开地址验证，拒绝含账号、私网与本机地址；同源相对图片和已有 PNG/JPEG/WebP base64 上传继续支持，不允许 SVG、脚本或外部 HTTP 地址。图片禁止发送来源信息，延迟加载。
- 单项输入使用对应 `label`，字段说明通过 `aria-describedby` 关联；多选使用 `fieldset/legend` 和独立选项标签，保持必填规则和所选值。

行为边界未变：v1 的表单及推广参数、v2 的 activityId 与返回契约、发布字段与顺序、必填校验、奖励领取、免费试课匹配、提交待审核、问卷不生成线索、原始幂等提交编号与提交结果不确定时的锁定/重试均保持原流程。表单不会自动增加课程目录或替换活动。

`frontend-tests/public-form-presentation.test.cjs` 运行真实前端脚本，覆盖字段顺序与可访问性、图片来源及失败事件、必填阻断、v1 不确定提交重试与优惠券回执、v2 活动问卷与资料回执、试课筛选/清空/原始时段提交。测试使用隔离模拟资料，不连接线上业务数据。
