# CRM·教务综合系统

思跃 CRM 与教务综合系统的本地交互原型备份。快照日期：2026-10-10。

## 打开方式

下载仓库后直接打开 `index.html`，无需安装依赖。Windows 也可双击 `打开原型.cmd`。

## 当前内容

- 按身份展示的工作台、全局操作搜索、线索登记及跟进。
- 课程、班级、学生、报名订单和营销优惠原型。
- 老师及学生毛毛虫课表、校区及教室表格课表。
- 批量建班、批量报名、批量学生转班、批量班级转校区。
- 机构资料，以及考勤、调课、转班、进班规则配置。

## 使用边界

这是前端演示原型，不是已上线的生产系统。页面身份切换不能替代服务端权限控制，支付与退款为演示流程。部分功能仍有原型限制，以页面说明为准。

业务数据和配置保存在当前浏览器的 localStorage 中；本仓库备份源码、内置示例数据与说明文件，不包含浏览器运行期间录入的数据。更换浏览器或文件路径后，原有数据可能不再可见。

`backup-manifest.json` 记录此次原型文件的 SHA-256，可核对备份内容。此仓库是本次快照，后续本地修改不会自动同步到 GitHub。
